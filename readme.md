**Housing Prices Competition for Kaggle Learn Users**

Предиктивная аналитика стоимости недвижимости.

Что было сделано:
* **Feature Engineering:** Генерация признаков общей площади помещений и возраста строения на основе дат постройки/ремонта.
* **Data Preprocessing:** Обработка пропусков, применение Ordinal Encoding для категориальных признаков.
* **Моделирование:** Построена модель регрессии на базе градиентного бустинга.

Результат:
MAE = 14929

Стек:
Python, pandas, xgboost
